# Global Crowdfunding Performance Analytics

## 📊 Project Overview
This project analyzes a global crowdfunding dataset to identify drivers of campaign success. It features a complete data pipeline from raw data cleaning to interactive visualization.

## 🛠️ Tech Stack
* **MySQL:** Data Engineering, ETL, and Financial Year modeling.
* **Excel:** Data profiling and initial statistical validation.
* **Power BI:** Executive KPI tracking and DAX modeling.
* **Tableau:** Geographic trend analysis and visual storytelling.

## 🚀 Key Features
* **Time Normalization:** Converted Unix timestamps into natural dates.
* **Custom Financial Calendar:** Built a reporting model starting in April (Fiscal Year logic).
* **Success Metrics:** Calculated success rates by category, location, and funding goal ranges.
